Как работает система

  1. Вы загружаете файл с работой студента.
  2. Gateway сохраняет файл в сервисе хранения и запускает анализ.
  3. Сервис анализа сравнивает работу с уже загруженными.
  4. Если найдена похожая работа другого студента, выставляется флаг плагиата.

Результат проверки

Отправьте работу, чтобы увидеть результат.
